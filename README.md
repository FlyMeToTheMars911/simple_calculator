# 清算 · 科学、投资与汇率计算器

适用于 Windows 11 的原生 WPF 桌面应用。免安装，无第三方运行时、浏览器内核或遥测。科学计算和投资组合可离线运行，汇率转换按需联网取得公开参考汇率。源码、构建脚本与可运行程序均在本目录。

## 运行

双击 **`ClearCalc.exe`**。分发时保留同目录的 `ClearCalc.exe.config`，也可直接解压 `ClearCalc-portable.zip` 后运行。

使用 Windows 11 内置的 .NET Framework 4.8 / 4.8.1，不需要安装 Python、Node.js 或 .NET SDK。系统支持范围参见 [Microsoft 的 .NET Framework 安装说明](https://learn.microsoft.com/en-us/dotnet/framework/install/)。

## 科学计算

- 四则运算、括号、乘方、平方／立方、任意次方根、倒数、绝对值、阶乘、取模、百分数、π、e、对数与指数。
- 三角、反三角、双曲及反双曲函数，支持 DEG / RAD / GRAD。`2ⁿᵈ` 切换第二组按键。
- `floor`、`ceil`、`trunc`、`round`、`min`、`max`、度分秒转换及随机数。
- 可在表达式任意位置编辑、选区替换、剪切、复制、粘贴、回退、撤销及重做。保持原始表达式，计算后也能修改。
- 实时预览；按 Enter 或 `=` 才正式记录。错误计算也会保留。清空表达式不会清除历史。
- 本次运行内不设置历史条数上限；可复制、回填、复用结果或导出 TXT。列表使用虚拟化显示。
- `Ans` 为上一条成功的科学计算结果。回填历史时，自动恢复角度制并将原来的 `Ans` / `mem` 固定成当时的值，避免重新计算时发生变化。
- `MS` 新增内存值；`MR` / `M+` / `M−` 操作最新一条；`M ▾` 查看所有内存；`MC` 清空全部内存。

### 编辑规则

选中文字时，一元函数作用于选区；未选择时，平方、根号、绝对值、对数等按键作用于整个表达式。三角函数菜单在光标处插入函数括号，可先选中需要包裹的部分。

`exp` 按键输入科学计数法的 `E`，例如 `2.5E6`；表达式函数 `exp(x)` 表示 e 的 x 次幂。小写 `e` 单独使用表示自然常数。

`^` 按右结合计算，`2^3^2 = 512`；乘方优先于前置负号，`-2^2 = -4`。阶乘优先于乘方。`%` 始终表示除以 100，因此 `100+10% = 100.1`；上涨 10% 请写 `100*(1+10%)`。`mod` 为保留被除数符号的余数。

支持隐式乘法：`2π`、`2(3+4)`、`2sin(30)`；隐式乘法与显式乘除同级并从左到右运算，建议用括号明确分母，例如 `1/(2π)`。小数点使用 `.`，函数参数以逗号分隔。

| 快捷键 | 操作 |
| --- | --- |
| Enter / `=` | 计算并记入历史 |
| Shift+Enter | 表达式换行 |
| Backspace / Delete | 删除光标前／后的字符或选区 |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Ctrl+L | 聚焦并选中表达式 |
| Ctrl+Shift+C | 复制当前计算结果 |
| Esc | 清空表达式，允许撤销 |
| F9 | 改变表达式或选区的正负号 |

示例：

```text
(128.6 - 112.4) * 300 - 8 - 12
sin(30)^2 + cos(30)^2
log(8, 2)
root(27, 3)
round(123.456, 2)
5!
```

## 投资组合

点击“投资组合”，添加持仓并双击单元格编辑。可以将 `持仓示例.csv` 导入体验，示例仅为演示数据。

输入名称、持仓数量、买入均价、当前价格、买入费用与预计卖出费。支持基金等带小数的份额。买入均价不含单独填写的费用；若你填写的是已含费成本，请将买入费用填为 0，避免重复计费。

| 指标 | 计算方式 |
| --- | --- |
| 投入成本 | 数量 × 买入均价 + 买入费用 |
| 当前市值 | 数量 × 当前价格 |
| 预计净收益 | 市值 − 预计卖出费 − 投入成本 |
| 收益率 | 净收益 ÷ 投入成本 × 100% |
| 市值占比 | 单项市值 ÷ 组合总市值 × 100% |
| 保本卖价 |（投入成本 + 预计卖出费）÷ 数量 |
| 组合收益率 | 总净收益 ÷ 总投入成本 × 100% |

费用按**金额**输入，不是费率。保本价按你填写的固定卖出费计算；若费用随成交额变化，应先估算对应费用。零成本、零数量或零总市值时，对应比率显示 `—`。输入错误会暂停整个组合的汇总，并显示错误位置，避免静默漏算。

“补仓均价试算”按 `(原数量 × 原每份含费成本 + 补仓数量 × 补仓价格 + 本次费用) ÷ 合计数量` 计算。可以带入选中持仓；试算不会自动改动持仓。点击“计算并记录”保存公式与精确结果。

“记录汇总”将当前持仓明细、费用、总成本、市值、收益率及净收益保存为历史快照。科学页中的投资记录“回填”会带入结果数值。

所有持仓须换算为**同一币种**，数量和价格须非负；这是当前持仓的成本收益试算，不是完整交易流水账。不自动取得行情或税率，不自动转换持仓币种；可先在“汇率转换”页换算金额，再手动填入。不统计分红、已实现收益、空头持仓和杠杆。价格、税费均由你按需要填入。

### 保存与导入

历史和持仓只保留到本次程序关闭，不自动写入磁盘。需要保留时，关闭前导出历史 TXT 和持仓 CSV。CSV 包含输入以及精确计算值，可用 Excel 打开，也可下次导回本程序。

示例文件和程序导出的 CSV 均使用 **UTF-8 BOM 编码与 Windows 换行**，让 Excel 双击打开时正确识别中文。用 Excel 修改后另存时，请选择“CSV UTF-8（逗号分隔）”，以便本程序再次导入。编码识别方式参见 [Microsoft 的说明](https://support.microsoft.com/en-us/excel/opening-csv-utf-8-files-correctly-in-excel)。

导入使用 UTF-8 CSV，**追加**到现有持仓，不合并同名标的。全部行验证通过后才追加，不会部分导入。前六列表头必须依次为：

```csv
名称,持仓数量,买入均价,当前价格,买入费用,预计卖出费
示例基金,1200,3.25,3.68,5,5
```

## 汇率转换

点击“汇率转换”，选择原币种、目标币种并输入非负金额，即时显示转换结果。支持 `.` 小数点及科学计数法（例如 `1.5E3`）。支持人民币、美元、欧元、英镑、日元、港币、新台币、韩元、澳元、加元、瑞士法郎、新加坡元、新西兰元、泰铢、马来西亚林吉特、印度卢比、印度尼西亚盾和阿联酋迪拉姆，共 18 种常用币种。

- `⇄` 互换币种，保留输入金额；“带入科学计算结果”使用科学页当前有效结果作为金额。
- 显示 `1 原币种 = 汇率 目标币种` 和**汇率数据日期**；“刷新汇率”重新联网获取。
- “复制结果”复制精确数值；“结果接着算”把结果带入科学页；“记录转换”或金额输入框中的 Enter 保存转换快照，包含金额、币种、汇率、日期及来源，可在历史中回填或导出。
- 异步请求不会阻塞界面；切换币种后清除旧结果，过时请求不会覆盖当前币种。输入错误、溢出或汇率不可用时，转换操作暂停。

数据源为 [Frankfurter 的公开 API](https://frankfurter.dev/)，无需账号或 API Key。请求 `https://api.frankfurter.dev/v2/rate/{原币种}/{目标币种}`，使用其央行及官方机构发布的每日参考汇率。节假日可能沿用最近发布的数据；**参考汇率不等于银行实时成交价**，转换不计手续费。

启动应用不会请求汇率。打开转换页或切换币种时检查本次运行缓存，缓存有效期为 1 小时；手动刷新跳过缓存。同一币种按 1:1 换算，无需联网。获取失败时，只能使用本次运行中已成功获取的同一币种对缓存，并明确显示获取失败、数据日期及最近成功获取时间；没有对应缓存则显示错误和 `—`。重启后需要重新获取，缓存不写入磁盘。

请求仅包含币种代码，金额、表达式和持仓均不会上传。公共服务的可用性及请求限流由数据源维护方管理。

## 精度

- 科学计算使用 IEEE 754 双精度浮点数，约 15～16 位有效数字；显示使用 15 位，内部保留双精度。极大整数和超小差值存在浮点精度限制。
- 投资页及汇率转换使用 `decimal` 十进制运算，约 28～29 位有效数字；投资页普通金额显示到两位小数，保本价和均价预览显示到六位，汇率和转换结果显示可用精度，**计算过程不按界面小数位截断**。CSV、投资及汇率历史保留 decimal 值。运算仍受 decimal 有限精度和范围约束。
- 将投资或汇率结果带入科学页后，后续计算使用科学页的浮点精度。
- 实数计算；阶乘支持非负整数至 170。表达式最多 16,384 字符，嵌套有安全上限，错误输入不会被当作脚本执行。

## 构建与验证

在本目录打开 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

构建使用系统 .NET Framework 编译器，无需下载 SDK 或 NuGet 包。`-Test` 会编译并执行核心测试、在屏幕外运行真实 WPF 窗口交互检查，并将科学、投资及汇率的布局截图和测试结果写入 `artifacts`。汇率测试使用模拟服务，覆盖精度、缓存、超时、取消、错误及请求竞争，无需联网；测试截图中的汇率仅为模拟数据。重新生成图标可运行 `scripts/make-icon.ps1`。

程序正在运行时，可使用 `-OutputDirectory .\artifacts\release` 将新版及配置写入另一目录，避免覆盖运行中的 EXE。执行过 `-Test` 后，可单独运行 ` .\artifacts\CoreTests.exe --rates-smoke` 验证真实汇率接口（需要联网）。

源码结构：`src/ExpressionEngine.cs` 为表达式解析，`CalculatorSession.cs` 为会话历史与内存，`Portfolio.cs` 为十进制投资计算与 CSV，`ExchangeRates.cs` 为汇率请求、验证及会话缓存，`CurrencyPage.cs` 为转换交互，`App.cs` / `MainWindow.xaml` 为主界面。源代码及 XAML 均嵌入或编译进 EXE，运行时无需保留 `src`。
